04. Ouvrir la boîte à outils

Éléments optionnels inclus
Objectifs

Suivre un acquis précis

L’objectif « comprendre le manifeste » possède son propre score et son statut. Il ne modifie pas automatiquement ceux de la capsule.

const report = SCORM12.setObjective({
  id: "comprendre_manifeste", raw: 80,
  min: 0, max: 100, status: "passed"
});
const committed = SCORM12.commit();
console.log(report, committed);
Les objectifs sont optionnels pour le LMS.

    05. Fermer la boucle

    Statut ≠ fermeture de session
    Fin de parcours

    Une capsule bien terminée, c’est une trace bien sauvegardée.

    Marquer « terminé » change le statut. Quitter envoie la durée, sauvegarde et ferme la communication. Pour reprendre une activité plus tard, choisissez « suspendre ».

    Autres statuts et raisons de sortie

    logout indique une intention ; le SCO ne déconnecte pas lui-même le compte LMS. La sortie normale utilise une chaîne vide.

    Voir le code à copier
    // [FR] Terminer le contenu sans fermer immédiatement la communication.
// [EN] Complete the content without immediately closing communication.
if (SCORM12.setStatus("completed")) SCORM12.commit();

// [FR] À appeler au moment où l'apprenant quitte réellement la capsule.
// [EN] Call when the learner actually leaves the lesson.
const closed = SCORM12.finish("suspend");
console.log(closed);
    La communication est fermée. Vous pouvez revenir au LMS. En simulation, rechargez la page pour ouvrir une nouvelle session et vérifier la reprise.
