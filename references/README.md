# Références conservées

Ce dossier conserve les livres ADL SCORM 1.2 et les schémas d'origine qui ont servi à vérifier le gabarit. Leur provenance, les modifications apportées aux copies utilisées et les limites des vérifications sont documentées dans [doc/SOURCES.md](../doc/SOURCES.md).

Les PDF et les schémas originaux sont volontairement conservés sous contrôle de version : ce sont des sources documentaires de référence, pas des résultats de compilation. Cette exception préserve l'information utile à la maintenance du projet. Leurs droits restent distincts de la GPL du code original ; voir [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md).

Les extractions automatiques `rte.txt` et `SCORM-12-CAM.txt`, lorsqu'elles existent localement, restent sur le disque mais ne sont plus suivies par Git. Elles sont dérivées des PDF originaux, qui demeurent disponibles. Aucun contenu pédagogique des guides n'est supprimé lors de cette évolution.
